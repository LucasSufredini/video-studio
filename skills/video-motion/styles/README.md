# Guias de estilo

Cada arquivo `.md` aqui descreve um estilo de vídeo: ritmo de corte, tipografia, cores, tipo de legenda, transições e jeito do gancho. A skill lê o guia que combina com o pedido ("faz no estilo X").

- Para criar um: mande vídeos de referência ao Claude e peça um guia de estilo.
- Guias pessoais (seu canal, um cliente) não vão para o GitHub: o `.gitignore` ignora tudo nesta pasta, menos este arquivo.
- Para compartilhar um guia com o time, adicione-o à força: `git add -f skills/video-motion/styles/<nome>.md`.
